# ARES Accord: Multi-Agent Resource Negotiation

Welcome to the ARES Accord 24-Hour AI/ML Hackathon! 

In this challenge, you will build an Agentic AI (Multi-Agent) system to handle a Mars Colony Emergency. Five specialized AI agents must negotiate over limited resources (Power, Water, Oxygen, Robot Time, Bandwidth) and reach a mathematically valid consensus before the colony collapses.

## 📂 Repository Contents

This repository contains all the starting materials you need to understand and execute the challenge:

- 📄 **`ARES_Accord_24_Hour_Hackathon_Challenge_v2.2.pdf`** - The main challenge guide, scenario details, and requirements. **(Read this first!)**
- 📄 **`RULES.md`** - A quick summary of the hackathon rules and allowed tools.
- 📄 **`output_schema.json`** - The exact JSON structure your agents must use to submit their votes and resource requests.
- 📄 **`event_injection_format.json`** - The JSON format the judges will use to inject a mid-run "Crisis" into your UI.
- 📄 **`submission_checklist.md`** - A final checklist to review before you submit your project.
- 📄 **`judges_scoring_rubric.md`** - The 100-point rubric the judges will use to evaluate your system.

## 🚀 Getting Started

1. Clone this repository to your local machine.
2. Read the Participant Guide PDF entirely.
3. Design your agent architecture (Commander + 4 Departments + Validator).
4. Build a visual UI (Streamlit, Gradio, Chainlit, etc.) to display the live negotiations and resource states.

Good luck, Commander! The survival of Ares Colony depends on your AI system.
